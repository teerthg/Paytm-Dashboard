# Paytm Transaction Dashboard

This repository contains a **Power BI dashboard** that visualizes **Paytm transaction data**. The dataset includes information about user transactions, revenue, user retention, and much more. The dashboard provides insights into transaction values, user behavior, and other key metrics across various dimensions such as **City**, **User Age**, and **Device Used**.

## **Dashboard Overview**
The Paytm dashboard includes the following key visualizations:
- **Total Revenue**: Displays the overall revenue from user transactions.
- **Total Transaction Value**: Visualizes the total transaction value across different user types and cities.
- **User Retention**: Shows the retention rate for users categorized by **Retained**, **New**, and **Churned**.
- **Revenue by User Type**: Highlights the revenue generated by **New** vs. **Returning** users.
- **Transaction Value by Time Slot**: Displays transaction values during different times of the day.
- **Revenue per Transaction Type**: Breakdown of revenue across different transaction types like **Peer-to-Peer**, **Bill Payment**, and **Recharge**.

## **Dataset Overview**
The dataset consists of the following columns:
- **Date**: Date of the transaction.
- **User ID**: Unique identifier for the user.
- **Transaction ID**: Unique identifier for the transaction.
- **Transaction Type**: Type of the transaction (e.g., Recharge, Peer-to-Peer).
- **Transaction Value**: The value of the transaction.
- **Revenue**: Revenue generated from the transaction.
- **User Age**: Age of the user.
- **User Gender**: Gender of the user.
- **City**: The city of the user.
- **Device Used**: The device used for the transaction (e.g., Desktop, Tablet).
- **User Retention**: User retention status (e.g., Retained, New, Churned).
- **Time of Day**: The time of day when the transaction occurred.
- **Day of the Week**: The day of the week when the transaction occurred.
- **User Type**: Type of the user (New or Returning).

## **Data Analysis**
The following analysis has been performed on the dataset:
- **Transactions by City**: Identifies the cities with the highest number of transactions.
- **Transactions by Age Group**: Analyzes how different age groups contribute to total transaction value.
- **Day of the Week Analysis**: Looks at how transactions fluctuate across different days of the week.
- **Revenue and Retention Analysis**: Examines how retention status impacts total revenue.

## **Dashboard Features**
- **Interactive Filters**: Users can filter the dashboard based on different metrics such as transaction type, user type, city, etc.
- **Time-based Insights**: The dashboard includes time-series analysis to explore transaction patterns over time.
- **User Segmentation**: Users are segmented based on transaction behavior and retention status to identify trends and patterns.

## **How to Run the Dashboard**
1. Clone the repository to your local machine.
2. Open the **Power BI** file using Power BI Desktop.
3. Connect the Power BI dashboard to the dataset stored in this repository.
4. Interact with the dashboard by selecting various filters to explore the data.
